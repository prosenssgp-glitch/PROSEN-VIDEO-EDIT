# PROSEN VIDEO EDIT

A lightweight browser-based video editor prototype. Open `index.html` or run `npm install` then `npm run dev`.

## Included
- Import local video by file picker or drag-and-drop
- Preview controls and seeking
- In/out trimming
- Brightness, contrast, saturation and preset looks
- WebM export using browser MediaRecorder (Chrome/Edge recommended)

Imported media stays in the browser. Export records the edited preview in real time; browser codec support varies. This is an initial prototype; multi-track editing, captions, transitions and advanced audio tools can be added in later iterations.
